## 0. 这份词表是什么

标注的最小单位。**level-2 是 17 个教材模块（已有），level-3 是本表 120 个知识单元。**

| 规则 | 说明 |
| --- | --- |
| ID 格式 | `kp_{模块两位}_{序号两位}_{英文slug}`，例 `kp_03_02_tangent` |
| 唯一性 | 全库唯一，终身不变；改名字不改 ID |
| 落位 | level-3 词条挂在对应 level-2 模块下，`tree_node` 沿用模块名 |
| 使用前提 | **每条必须有定义 + 典型例题 + 反例**才能用于标注；本草案只写了定义，例题与反例在 pilot 阶段补齐 |

1. **「选做题」不再作为独立知识模块**（2026-11-05 解散）：极坐标、参数方程归入解析几何，绝对值不等式、柯西不等式归入不等式，证明方法移入 Method 体系。考试组织形式不等于知识领域。
2. **函数模块 13 项最多**：函数是高考综合题的底座，拆细才不会让「函数」变成万能垃圾桶标签。
3. **没有单列「数学文化」「应用题」**：它们是题型维度，不是知识维度，应由 `question_type_id` 或标签处理，不混进知识点。
