### A2 · 教师走查 ✅ 已完成（1 人 / 场景 A）

**样本**：1 位高中数学教师，教高三，教龄 3 年。只跑了场景 A（从零备一节课）。

**结果**：

| 问题 | 回答 | 结论 |
| --- | --- | --- |
| 计划审批页能否说清在批准什么 | 能 | G3 保留，门禁模型成立 |
| 有没有想跳过的步骤 | 没有 | 七道门禁的认知负荷可接受 |
| 有没有“不如自己写” | 没有 | 价值主张成立 |
| 术语是否一致 | 一致 | “项目 / 材料 / 草稿”可用 |
| 检查结果页是否看证据 | 点开了 | S0–S3 分级可被主动查看 |
| 学生版“已核对 0 个答案”是否可信 | **“我得自己下载看一下”** | **假设被证伪**，见下 |
| 可接受等待时长 | 20 分钟内 | 与 M7 的 P50 ≤ 4 min 一致 |

**被证伪的一条**：教师不信“系统已核对”这类自证式声明。处置见 §D.19 与 D5 §7.3——改为先预览、后下载。

**没有覆盖到的（重要）**：

| 场景 | 验证什么 | 状态 |
| --- | --- | --- |
| B 改讲义 | D1-03「教师编辑不重审 Plan」 | **未验证** |
| C 课堂小测 | G3 自动批准是否可接受 | **未验证** |
| D 纸质资料 | 知识库上传值不值得做 | **未验证** |

**D1 最核心的那条判断（编辑与审批分权）恰恰在未跑的场景 B 里。** 这不影响 D3 开写，但那条判断仍然只有推理支撑，没有用户证据。

**样本折扣**：教龄 3 年的年轻教师对流程化工具的容忍度通常高于 10 年以上教龄的老教师。这组“没有负面反馈”的结果不宜外推。

## E. 判断规则

**需要你拍板的**：

- 法务、授权、合规类事实
- 真实用户行为（走查结果）
- 商业取舍（范围、优先级、上线时间）
- 资源规模（平台知识库有多少内容）

**不需要你拍板的**（我直接定，事后报告）：

- 文档结构、契约格式
- 状态机、动作、接口形状
- 错误码、文案
- 验收指标
- 技术方案选型（在既有技术栈内）
