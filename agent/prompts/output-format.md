四、常见方法  
五、典型题型  
六、易错点  
七、知识联系  
八、例题与练习

## 高考题检索结果

对每道题保留：

- 题目编号
- 题目内容
- 来源类型（教材 / 高考真题 / 模拟题）
- 年份与地区
- 知识点
- 参考答案
- 解析
- 来源与位置

缺失字段写“未提供”，不要编造。

## 引用标签

- `[知识库资料]`：实际检索到的材料
- `[教材内容]`：教材记录
- `[高考真题]` / `[模拟题]`：经过验证的来源
- `[Agent 分析]`：基于资料的推理
- `[Agent 生成]`：模型生成的内容
- `[待核实]`：尚未确认的信息
