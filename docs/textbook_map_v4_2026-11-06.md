## 0. 结论先行

- **74 条 exact 不一致：fixed 74 / still 0 / new-wrong 0**（new-wrong 必须 0，已满足）。
- 360 复核内容块（327 分母）：模块 **308→327**（94.2% → 100.0%），exact **253→327**（77.4% → 100.0%），any 253→327。
- 全量 1437 个 model 块中 **188 块** primary/status 变化（13.1%）；其中 mapped→mapped 162 块、vocab_gap→mapped 26 块（含 74 条中 15 条空错 + 11 条节候选兜底）；non_content 不变。
- 做法不是“重写打分”，而是：**v3 映射为基线（可复现、逐块一致）+ 节级内容规则修正层**。原因是 360 之外 1437 块没有教师标签，整段重建会给未复核块制造不可审计的系统性改动；v4 中未命中任何规则的 1223 块与 v3 输出完全一致。
- 360 的 100% 是“风险分层过采样样本上的拟合结果”，**不能外推为全量 100%**（见 §6 局限）。

## 6. 方法论局限（必须与数字一起读）

1. **360 是风险分层过采样样本**：抽样时按“低置信 / vocab_gap / non_content / 正常”分层，低置信与 gap 被显著放大（360 里 vocab_gap 16 条、低置信 45 条）。v4 在 327 分母上 100% 是“拟合该样本”的结果，**不能推出全量 1437 块 100% 正确**；真实全量准确率只能用新的随机样本估计。
2. **规则与评估同源**：规则是看着 360 的 74 条错因设计的（节号+正文证据，但不是独立来源），因此 360 上的 fixed 有乐观偏差；new-wrong=0 只能保证“没有在原 253 条正确块上翻车”，不能保证新规则在其他块上不误伤。
3. **held-out 缺失**：100 条 pilot 教师标签文件当前不在盘上（`pilot_result.md` 只有 88 条摘要，无逐块标签），无法做真正的 held-out 检验；本报告没有使用任何 held-out 数字。
4. **窄规则含教师口径**：如 8.1 结构 → `kp_08_03_position`、9.3 统计案例 → `kp_10_03_central`、5.7 节末复习 → 同角/和差角、7.3 三角表示 → `kp_06_04_geometric`。这些是“词表无更贴切条目时按教师约定归最近邻”，已在规则表与 §4.3 逐条披露；若后续词表新增“空间几何体结构 / 复数三角表示，应重新标注。
5. **节级重选的边界**：SEC 重选对“节内混排”仍偏粗（例 5.5.2、2.5.2 章末复习块），其变化已列入 §4.3；未复核块若发现更优口径，应在 v5 用教师复核修正。
6. **加权全量估计未重算**：v3 的 96.0%/80.5% 是风险分层加权估计，依赖“同层样本可代表全量”的假设；v4 改变了部分块的风险层（gap→mapped、低置信），本报告不重算加权值，避免用同源样本制造第二个无依据数字。
