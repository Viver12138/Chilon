# 教材块映射 100 块 pilot 与教师核对结果（摘要）

> 范围：PG `textbook` **1797 块 / 5 册**中抽样 **100 块**（每册 20，页跨度均匀，seed=20261106，含少量封面/目录/前言等非内容块）。
> 只读 PG；**未写 PG、未改 vault、未调 OCR**。教师核对由用户提供的回填表完成，本记录按其字段统计。

## 3. 典型错误与根因

- 平面向量 / 空间向量混（如“空间向量基底证垂直”被判到平面向量）；
- 函数 / 三角函数平移混（正弦曲线平移被判到函数图像变换）；
- 对数 / 回归混（相关系数、最小二乘、回归方程被判到对数函数）；
- 圆的方程 / 充要条件混（充要条件例题被判到圆的方程）。

**根因**：教材块是 OCR 的页/part 碎片，只有 `page/part`，**没有 chapter/section**；同一页块常混排章节导引、例题、习题与跨节内容，模块级判断因此系统性偏移。

## 4. 结论：先补章节结构，再全量

- **不建议直接全量 1797 块**：低置信与 vocab_gap 集中在“章末复习 / 多节混排 / 前言导引”；
- **先补 chapter/section**（可从 PDF 目录/TOC 或教材页眉半自动推断），并明确 non_content / 教材栏目规则，再重跑 pilot；
- 词表可少量增补（数学建模、阅读与思考、探究、信息技术应用等栏目）。
