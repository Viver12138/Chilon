# Chilon 使用说明（教师版）

> 面向：高中（高考）数学教师
> 版本：0.2 · 2026-11
> 这份说明只讲**你怎么用**，不讲技术。

---

## 一句话

**你说清楚这节课教什么，Chilon 出执行方案、做出材料、自查一遍；你审批、修改、导出。**

它不替你做决定，也不替你负责。它把"从一句话到一份能发给学生的材料"之间那些重复劳动接过去。

---

## 它做什么，不做什么

| Chilon 做 | 你仍然要做 |
| --- | --- |
| 把你的需求拆成可执行的步骤 | 判断这个方案对不对、该不该批准 |
| 从题库与教材里找依据 | 判断引用的题目是否适合你的学生 |
| 起草题目与讲解 | 决定讲解的方式与深度 |
| 自查结构、引用、计算 | 对最终内容负责 |
| 生成教师版与学生版两个文件 | 决定什么时候发、发给谁 |

**一句话：它是备课的助手，不是替你上课的人。**

---

## 一次完整的备课：五步

### 第 1 步 · 说出你的需求

一句话就行。例如：

> 用高考题和模拟题，出 12 道三角函数题，一节课的量。

它会听出三件事：**课题**（三角函数）、**来源**（高考题、模拟题）、**题量**（12 道）。

**说不清的地方它不会编。** 如果你没提题量，它会按课题给一个默认值，并让你看到它选了哪个——而不是假装你说过。

### 第 2 步 · 看方案，决定批不批

它不会直接开始做，而是先给你一份**执行方案**：分几步、每步做什么、哪几步可以同时做。

例如它会说：

```text
① 检索依据              高考题、模拟题里的三角函数
② 生成前半（难度中）     依赖 ①
③ 生成后半（难度高）     依赖 ①
④ 结构、引用、计算自查   依赖 ②③
```

你可以：

- **批准** —— 它开始做
- **要求重做** —— 告诉它哪里不对，它重新出方案

**这一步是你权利的核心。** 方案没被批准，它不会动。

### 第 3 步 · 看它做到哪了

执行时你不需要盯着。每一步的状态会显示：等待、进行中、完成、失败。

失败时它会说清楚是**哪一步**失败、**为什么**，而不是只给你一个红叉。

### 第 4 步 · 改内容

对草稿的两条修改路径：

- **说话改**：告诉它"第 3 题太难了，换成基础题"
- **直接改**：在编辑器里改文字、改题、删题

两条路都行。改完是一个**新版本**，旧版本不会消失——你随时能退回之前看过的样子。

### 第 5 步 · 检查，然后导出

导出前它会自查一遍，结果分成两档：

| 级别 | 含义 | 你要做什么 |
| --- | --- | --- |
| **阻断** | 有问题不能发（如引用对不上原文） | 必须修 |
| **提示** | 建议看，但你可以判断 | 自己决定 |

看到"提示"你选择不改，需要写一句理由——**这不是走流程，是为了三个月后你还记得为什么放过它。**

## 功能详解

### 1. 提出需求

支持的内容：

- 来源：**教材 / 教辅 / 高考题 / 模拟题**，可多选
- 题量、课题、课型（新授课、复习课、习题课）
- 也可以直接贴一段你自己的描述

年级固定为**高三**（高考方向），不设难度档位——难度由你从题目里自己判断，比让系统猜更准。

### 2. 方案审批

方案里能看到：

- 分几步、每步做什么
- 步骤之间的依赖关系（哪些能并行）
- 每步会用到什么能力（检索、生成、校验）

**方案绑定的是"当时那份内容"。** 如果方案被批准后内容又改了，审批就会失效，需要重新批准。这是故意的：**批准一个你没看过的东西没有意义。**

### 3. 生成与进度

- 长任务会拆成多步并行，缩短等待
- 每步都能看到状态与耗时
- 中途失败可以从失败处继续，不用从头再来

### 4. 编辑

- 对话修改：适合"整体换个风格""难度降一点"
- 直接编辑：适合"这道题的选项改了""去掉第 5 题"

两者可以混用。每次修改都留痕，可以看历史、可以对比。

### 5. 质量检查

自查三类问题：

| 类别 | 查什么 |
| --- | --- |
| **结构** | 教案结构是否完整、题目是否有答案 |
| **溯源** | 引用是否真的来自那份资料，页码题号是否对得上 |
| **数学** | 计算是否正确、等式是否成立、定义域是否考虑 |

**数学检查分五层**：公式写法、符号推导、数值代入、解题步骤、跨材料一致性。

关于这一项有个诚实说明：**它不会只凭"我觉得对"就告诉你通过。** 每一条"通过"背后都有可展开的证据（计算过程、比对结果）。证据拿不出来的，会标成"无法判定"，而不是"通过"。

### 6. 发布与版本

发布后产生一个**正式版本**：

- 正式版本**不可修改**
- 任何修改都产生新版本，旧版本永远可查
- 正式版本会记录：谁批准的、什么时候、依据了哪些检查

**为什么不能改**：因为发给学生的东西必须能被追溯。如果一份材料能被悄悄改掉，"学生手上那份"就说不清了。

### 7. 导出：教师版与学生版

一次导出两个文件，**内容同源**：

| 版本 | 内容 |
| --- | --- |
| **教师版** | 含答案、含讲解、含引用出处 |
| **学生版** | 不含答案与讲解 |

学生版**不是把答案藏白字**，而是从源数据里根本不生成答案。所以复制、另存、转换格式都拿不到答案。

导出前可以**预览**，看到的就是下载后的样子。

### 8. 知识库

分两层：

**平台层**（现成的，直接用）

| 分类 | 内容 |
| --- | --- |
| 人教版教材 | 教材原文 |
| 教辅 | 教辅例题 |
| 高考题 | 历年真题 |
| 模拟题 | 各地模拟卷 |

**你自己的层**（上传的）

- 整卷上传，系统自动切分成一道道题
- 默认**只有你能看到**，其他教师看不到
- 你可以建自己的分类

### 9. 溯源

每一处引用都能点开：

- 来自哪本书、哪一年、哪份卷
- 第几页、第几题
- 原文那一段

**用途**：当它引用一道题时，你能立刻判断它有没有断章取义、题目是不是被改了。

## 关于你的资料

**版权**：平台层内容已取得授权，可复制、改编、发给学生、与其他内容混排。你自己上传的资料，权利与责任都在你。

**可见性**：

| 资料 | 谁能看到 |
| --- | --- |
| 你上传的 | 只有你（默认私有） |
| 平台层的 | 所有教师（只读） |

**你的教学目标、草稿、材料，其他教师看不到。** 这是系统层面的隔离，不是界面层的隐藏。

---

## 你不必担心的事

**① 它不会替你批准任何东西。**
方案、发布，每一次都要你点头。没有"自动通过"。

**② 它不会自证清白。**
你不会看到"已核对 0 个答案，全部正确"这种话。看不到证据的检查，就是没做检查。

**③ 学生版真的没有答案。**
不是隐藏，是没生成。导出后可以自己验证：搜索答案关键词，一个都不会有。

**④ 改不坏历史版本。**
正式版本一旦生成就不可变。你随时能翻到一个月前发出去的是哪一版。

**⑤ 中途失败不会留半成品。**
如果某一步失败，那一版就不会被当成"已完成"。你会看到明确的失败信息，而不是一份看起来完整、实际缺了内容的材料。

## 当前阶段（诚实说明）

这一节会随时间变化，所以在最前面标日期：**2026 年 11 月**。

**现在已经能用的：**

- 注册登录，说出需求 → 系统理解并结构化
- AI 生成执行方案（分步骤、依赖关系），你审批或要求重做
- 启动执行、查看步骤进度；失败会说明是哪一步、为什么
- 发布正式版本：不可修改、可追溯，能查到谁批准、依据了哪些检查
- 导出教师版与学生版 DOCX（也能导出 PDF）
- 知识库：整卷（PDF/JPG/PNG）上传切题、缺题复核与补录、检索与溯源
- 平台语料：6050 道高考真题、931 道模拟题、5 套教材

**还没做完的：**

- **编辑还没接到界面上。** 对话改、直接改目前只有服务端的版本记录，界面上还不能改草稿。
- **真人验收。** 只有场景 A 做过一次真实教师验证；场景 B/C/D 和现在这一版界面，还没有请老师实际走过。
- **知识库标注与抽检。** 全库考点标注已完成，但标注和第三轮抽检都是 AI 按教师角色模拟填写的（模块一致 97%–99%），**不是真人校对结论**。
- **检索质量。** 相关题能搜到，但“你要的那一道”不保证排进前几条；教材内容也常被高考题挤到后面。
- **真实课堂试用**还没有开始。

已经做到的写在这里，没做到的也不藏起来——这份说明宁可显得慢，也不能让你在需要它的时候才发现差别。

## 常见问题

**问：它会不会改动我上传的原卷？**
不会。上传的文件是只读的，切分出来的是副本。

**问：我说得笼统，它会怎么办？**
它会按课题给默认值，并把默认值显示给你看。说不清的关键信息（比如空需求），它会拒绝开始，而不是随便做。

**问：AI 写的题目会不会有错？**
会。所以有数学自查，也有"无法判定"这一档。**自查通过不等于绝对正确**，最终仍要你看过——这也是为什么每一步都要你审批。

**问：能撤回发布吗？**
正式版本不会被删除。撤回的语义是"不再作为当前版本"，历史仍然可查。

**问：其他老师能看到我的教案吗？**
看不到。教学材料按教师隔离。

**问：我能不能只用它找题，不用它生成？**
可以。检索与生成是分开的步骤，你可以只用前面的部分。
