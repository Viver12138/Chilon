# 教材映射 v3（section→kp 细化）结果（摘要）

> 范围：同一 100 块，用固定 chapter/section + `section→kp` 词典 + 正文关键词重跑映射（v3）。
> **映射阶段不读取教师标签**，教师标签只用于 v3 生成后的评估（分母 88）。
> 未调 OCR、未写 PG/vault、未 commit。

## 1. v3 规则

1. **chapter 层**：`chapter_num → 允许模块`，限制候选 kp 不跨章；
2. **section 层**：从 section 标题构建 `section→候选 kp` 词典（120 词表关键词 + 章节标题；人工 override 仅依据课标/节名，不看教师标签）；
3. **正文层**：120 词表关键词打分；词典候选 +4、section 标题 +2×分、正文分；
4. **secondary**：仅保留跨模块且证据 ≥3 的候选（修正 v2 的 any 下降问题）；
5. non_content / vocab_gap 规则不变。

- section 词典条目：**93**；有候选：**85**。
